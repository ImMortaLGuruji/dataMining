# SetuBid: Scalable Tender Deduplication Pipeline

[![Python 3.10+](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/downloads/)
[![Tests](https://img.shields.io/badge/tests-22%20passed-brightgreen.svg)]()

[![Budget](https://img.shields.io/badge/nightly%20budget-3.85%20min%20%2F%2020%20min-success.svg)]()

SetuBid is a production-grade deduplication and entity resolution system engineered for Indian public procurement tender notices aggregated across 260 distinct government portals.

---

## 🌟 Key Architecture & Highlights

- **Sublinear Candidate Retrieval**: Employs MinHash sketches ($m=256$) with Locality-Sensitive Hashing ($b=32, r=8$), slashing the comparison space from 72 million unindexed pairs down to 1.99 million candidate pairs in **1.60 seconds**.
- **Empirical Skew Mitigation**: Identifies and eliminates massive workload skew generated by nodal portals (P001–P006) through targeted preamble stripping and LSH bucket capping ($C_{\text{cap}} = 100$), reducing total candidate comparisons by **66.8%** and non-duplicate exposure by **52.4%** with zero material loss in recall.
- **Relational Persistence**: Uses DuckDB (`setubid.duckdb`) with an Adaptive Radix Tree (ART) secondary index on `(band_idx, bucket_key)`, examining only 24,992 rows vs 384,000 rows in full scans (`EXPLAIN ANALYZE`).
- **Stable Opportunity Identities**: Generates deterministic UUID v5 opportunity card IDs (`CARD-<hex>`) completely decoupled from source notice IDs, maintaining stability across process restarts, reruns, duplicate arrivals, and cluster reconciliations.
- **High-Performance Budget Adherence**: Full end-to-end nightly pipeline across 12,000 notices executes in **3.85 minutes (231 seconds)**, utilizing only **19.25%** of the 20-minute production budget.

## 🚀 Quickstart & Reproduction

### 1. Environment Setup

Ensure Python 3.10+ is installed:

```powershell
$env:PYTHONPATH='src'
```

### 2. Run the Test Suite

```powershell
py -m unittest discover -s tests -p "test_*.py"
```

All 22 unit tests execute and pass in < 1 second.

### 3. Run the Production Pipeline

To execute the entire end-to-end deduplication pipeline:

```powershell
py -u scripts/run_full_pipeline.py
```

This updates `setubid.duckdb` and writes `reports/tables/final_metrics.csv`.
